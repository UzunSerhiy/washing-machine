# №32M — первый этап: вкладки без запуска и блокировка переходов

- Убраны дублирующие кнопки переключения режимов из общей панели управления.
- Вкладки MANUAL/AUTO/CALIBRATION работают как навигация, без вызова `/mode/*` и без требования профиля материала.
- При активной операции, калибровке или подготовленной/работающей AUTO-сессии переход на другую вкладку блокируется.
- При недоступности любого из трёх статусов переход блокируется (fail closed).

**Ограничение:** это первый UI-патч, а не завершённая серверная модель сессий. Кнопки «Начать сессию» и «Завершить сессию» для MANUAL и общая backend-блокировка ещё не добавлены. Переключение вкладки не изменяет backend `operation.mode` — намеренно, чтобы не отправлять команды остановки или движения. Прямой ввод URL не блокируется. AUTO остаётся ограничен существующим backend режимом FAKE. Не использовать как единственный механизм безопасности.
