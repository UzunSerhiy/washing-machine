# STEP32P — щётки при ручной корректировке калибровки

Основа: v65 + №32O (этап 1) + №32O.2 (если установлен).

- Water Start: при ручном Forward и Reverse сначала включаются щётки, затем роллер.
- READY_TO_UNWIND: штатная автоматическая отмотка до Material Start не меняется.
- При достижении Material Start автоматическая отмотка останавливается и начинается WASHING_STOP.
- WASHING_STOP: при ручном Forward/Reverse щётки включаются автоматически.
- Pause останавливает щётки вместе с роллером на этапах корректировки.
- Stop останавливает все приводы, сохранённые точки не сбрасываются.
- Если запуск щёток или роллера вызывает исключение, отправляется STOP.

Внимание: проверка реального движения и подтверждения остановки по VFD выполняется существующими защитами проекта; программные тесты не заменяют испытаний оборудования.
