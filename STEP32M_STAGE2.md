# 32M stage 2A — выбор режима и MANUAL-сессия

- Переход вкладок вызывает POST /api/machine/mode/select; профиль не требуется, движения нет.
- Backend отказывает в выборе вкладки при активной AUTO/CALIBRATION/MANUAL-сессии, движении или проблемном HOME.
- MANUAL получает кнопки начала и завершения сессии.

ОГРАНИЧЕНИЯ: это промежуточный этап, а не завершённая серверная модель сессий. Старые API /mode/* остаются и не используют новую блокировку; ручные команды пока не требуют активной MANUAL-сессии. Завершение MANUAL проверяет программное состояние движения, а не подтверждённую телеметрию частотников. AUTO в REAL по-прежнему запрещён старой проверкой require_fake_auto(). Не считать этот патч достаточным для безопасной эксплуатации или для завершения всей задачи.
