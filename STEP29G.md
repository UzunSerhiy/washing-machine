# Шаг 29Г — авария во время отправки команды движения

В режиме REAL (`enforce_motion_preflight=True`) исключение из `Brush.start`, `Roller.forward` или `Roller.reverse` приводит к следующему:

1. Под общим `Machine._roller_lock` устанавливается программная аварийная блокировка.
2. Причина сохраняется в `MotionFaultStore` (если доступен).
3. Выполняется best-effort `stop_all()` для трёх приводов.
4. Исходное исключение передаётся вызывающему коду; автоматического RESET/RUN нет.

Ошибка записи файла не снимает блокировку в памяти. Физическая остановка **не подтверждается** попыткой STOP. После перезапуска REAL startup interlock остаётся обязательным.

Ограничения: патч не решает аппаратную гонку E15 между опросом и RUN; не заменяет физический E-STOP. Ошибки предварительной проверки до отправки команды и прямые вызовы драйверов рассматриваются отдельно. Тесты используют Mock, не оборудование.

Установка из корня проекта:

```sh
unzip -o ~/Downloads/washing-machine-step29g-command-failure.zip -d .
docker compose exec backend python -m pytest -q tests/test_motion_command_failure_latch.py
docker compose exec backend python -m pytest -q
```

Ожидается 6 новых тестов; если 5 тестов шага 29В уже установлены, всего 799. Полный набор локально не проверен из-за отсутствия `asyncpg` в среде подготовки.
