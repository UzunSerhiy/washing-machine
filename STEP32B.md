# STEP 32Б — операторское подтверждение программной блокировки

На странице MANUAL добавлен компонент восстановления для уже существующего backend POST `/api/machine/motion-fault/acknowledge`.

- Показывается только при активной блокировке или ошибке чтения.
- Запрос возможен только при `recovery_available=true` и явном подтверждении оператора.
- Backend самостоятельно проверяет остановку приводов, состояние сессий и другие условия.
- После успеха обновляются readiness и motion-fault; запуск не выполняется.
- Физический E-STOP и RESET остаются независимыми.

Проверка: `cd frontend && npm run lint && npm run build`.
