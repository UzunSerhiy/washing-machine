# STEP31E FIX1

Исправление `react-hooks/purity`: `Date.now()` больше не вызывается во время render.

Время обновляется таймером внутри `useEffect`, и при отсутствии свежих диагностических данных команды движения остаются заблокированными. Таймер очищается при размонтировании.

Проверка: `cd frontend && npm run lint && npm run build`. Реальные двигатели для проверки не запускать.
