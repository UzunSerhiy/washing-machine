# Шаг №30Г — конкурентные запросы во время восстановления

Добавлены 6 детерминированных тестов с имитацией трёх GAIN.

- RUN Brush/Roller forward/Roller reverse ожидает захваченный recovery lock и не отправляется при ошибке проверки E15.
- RUN Roller не обходит блокировку во время неудачной очистки HOME.
- Подготовленная AUTO-сессия и чужой владелец Roller запрещают подтверждение.
- Все проверки выполняются без реальных Modbus-команд и без изменений рабочего кода.

**Граница гарантий:** эти тесты не доказывают, что конкурентная команда, поставленная в очередь во время **успешного** подтверждения, будет отвергнута. После успешного снятия latch ожидающий RUN может получить lock и исполниться. Для запрета такого сценария нужен отдельный механизм нового разрешения/эпохи команд на уровне API и сервисов. Не считайте №30Г доказательством полной защиты от неожиданного запуска.

```bash
unzip -o ~/Downloads/washing-machine-step30g-recovery-races.zip -d .
docker compose exec backend python -m pytest -q tests/test_step30g_recovery_races.py
docker compose exec backend python -m pytest -q
```

Ожидается 860 тестов (854 + 6). Не коммитить до получения результатов.
