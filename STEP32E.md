# №32Е — диагностика переключения кнопок

Добавляет журнал в DevTools Console при изменении `allowed`.
Никаких изменений backend, RUN, STOP, аварийных блокировок и условий допуска.

Открой /manual, F12 → Console, фильтр `[motion-ui]`, скопируй 2–4 соседних события при мерцании.
В сообщении будут `isPending`, `isError`, `dataUpdatedAt`, `ageMs`, `data` для обоих запросов.
