# Шаг 12 — отображение HOME в интерфейсе (без движения)

В `frontend/app/calibration/page.tsx` подпись кнопки изменена с «Найти ноль (2 Hz)» на «Найти ноль (10 Hz)», поскольку `frontend/lib/calibration-api.ts` отправляет `frequency_hz: 10`.

Добавлено явное предупреждение: в режиме REAL сервер запрещает запуск HOME (HTTP 403). Ограничение не снимается. Частота, логика homing и управление приводами не изменяются.

## Применение
Из корня проекта распаковать ZIP с заменой файла, затем проверить `git diff` и запустить фронтенд. Для FAKE-тестирования HOME нужна активная сессия калибровки на этапе `set_zero`; backend также требует MANUAL и остановленных приводов.

## Проверка
- Убедиться, что кнопка показывает «10 Hz».
- Проверить, что предупреждение REAL видно под кнопкой.
- Убедиться, что backend в REAL по-прежнему возвращает 403.

Этот шаг не предназначен для физического запуска машины.
