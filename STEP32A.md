# №32А — MANUAL: актуальная скорость из backend

- Убраны фиктивные начальные значения 30% / 50%.
- Ползунки показывают значения `roller_speed_percent` / `brush_speed_percent`, полученные от FastAPI.
- После изменения ползунка значение остаётся локальным до Apply Speed / запуска.
- После успешной отправки локальное значение сбрасывается, UI снова показывает состояние backend.
- Отдельно отображается Applied speed, чтобы не путать выбранное и применённое значение.
- Кнопка Apply Speed недоступна, пока оператор не изменил ползунок.

Не менялись backend, RS485, правила безопасности и алгоритмы движения.

Проверка: `cd frontend && npm run test:safety && npm run lint && npm run build`.
