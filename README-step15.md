# Шаг №15 — диагностика подтверждения STOP

Этот патч **не снимает блокировку REAL** и не запускает двигатель.
Добавляет независимую функцию чтения состояния частотника и тесты.

Функция проверяет код состояния 3, нулевую выходную частоту и отсутствие fault.
При сбое Modbus и некорректных данных подтверждение невозможно.

Важно: выходная частота 0 Гц не подтверждает физическую остановку вала.
Для HOME ещё потребуются проверка механического движения/выбега, последовательные измерения, интеграция с RollerHomingService и независимый аппаратный останов.

Установка: `unzip -o ~/Downloads/washing-machine-step15-stop-confirmation.zip -d .`
Тесты: `docker compose exec backend python -m pytest -q backend/tests/test_stop_confirmation.py`
