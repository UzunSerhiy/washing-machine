# №32Г — устранение мерцания диагностики

Во время фонового обновления TanStack Query `isFetching=true`, но предыдущие успешные диагностические данные ещё действительны. Теперь UI использует их до истечения срока актуальности (3 с), при этом `isPending`, `isError`, устаревшие данные и аварии продолжают блокировать запуск. Backend и аппаратные защиты не изменены.
