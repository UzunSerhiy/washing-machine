# Шаг №30В — состояние после программного подтверждения аварии

Добавлены семь тестов (параметризованные случаи считаются отдельно), только имитация GAIN и ASGI HTTP, без обращения к оборудованию.

Проверяется: подтверждение не возобновляет AUTO/HOME и не посылает команды движения; последовательность очистки HOME → AUTO → CALIBRATION → глобальная блокировка; ошибка любой очистки оставляет глобальную блокировку; новая E15 после успешного подтверждения снова блокирует восстановление и требует нового подтверждения оператора.

**Ограничение:** поля `homed=false` и `automatic_restart=false` в HTTP-ответе сами по себе не доказывают реальное состояние механики. Здесь проверяется программный контракт, не функциональная безопасность физического E-STOP.

Установка из корня проекта: `unzip -o ~/Downloads/washing-machine-step30v-post-recovery-tests.zip -d .`

Тесты:
```
docker compose exec backend python -m pytest -q tests/test_step30v_post_recovery_contract.py
docker compose exec backend python -m pytest -q
```
Ожидается 7 новых тестов, всего 854 при неизменном составе предыдущего набора (847).

Не делать коммит до успешной проверки в Docker.
