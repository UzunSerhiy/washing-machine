# №31И — диагностический HTTP/Query интеграционный слой

Пять тестов используют реальные Axios и TanStack QueryClient, но **полностью подменяют HTTP adapter**. Тесты выполняют только GET запросы `/api/machine/readiness` и `/api/machine/motion-fault`, без подключения к оборудованию.

Проверяются: ожидание двух ответов, E15, ошибка сети при наличии старого кэша, просрочка успешных ответов и восстановление сети при сохраняющейся аварии.

Запуск из `frontend/`: `npm run test:safety`, затем `npm run lint` и `npm run build`.

Ограничения: не проверяется рендер React, disabled-кнопки и отсутствие отправки команд из компонентов. Сценарий снятия блокировки моделируется заменой ответа backend, **без вызова RESET/ACK**. Никакие тесты не разрешают физическое движение.
