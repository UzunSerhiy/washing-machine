# 32S1 — подготовка редактирования сохранённой калибровки

Добавлен GET /api/machine/calibration/saved/{material_profile_id} для чтения сохранённых точек из БД без запуска приводов. CALIBRATION показывает сохранённые координаты при выборе материала. Чтобы начать новую калибровку поверх существующей, нужно явно подтвердить выбор.

В этом этапе НЕ реализованы автоматические Next/Previous, ручная корректировка точки и атомарное сохранение черновика. Это подготовительный этап, который не изменяет работающий алгоритм калибровки и возврата Point0.

Проверено: py_compile API. Сборка frontend не проверена (node_modules отсутствуют).
